# S17. 꾹 누르기와 내 상자 다시 들기

- **묶음**: 2묶음 · 끌어안기와 되찾기
- **앞 단계**: S16
- **크기(어림)**: 보통
- **끝나면**: 버튼이 톡 누르기와 꾹 누르기를 가르고, 갑판의 내 상자를 꾹 눌러 다시 들 수 있다.

## 지킬 규칙

| 번호 | 규칙 |

| KR-6 | 조작은 이동과 버튼 하나다. 버튼을 누르는 방법은 톡 누르기와 꾹 누르기 둘이다. |
| IN-1 | 버튼의 대상은 가장 가까운 상자 하나이고, 대상에는 테두리가 뜬다. |
| IN-4 | 빈손으로 갑판에 있으면 톡 누르기는 되찾기다. 끌어안긴 내 상자가 손 닿는 거리에 없으면 아무 일도 일어나지 않고, 앞에 있는 상자에 고리가 잠깐 비쳐 꾹 눌러야 한다는 것을 알려 준다. |
| IN-5 | 빈손으로 갑판의 상자 앞에서 0.5초 꾹 누르면 남의 상자는 끌어안기, 내 상자는 다시 들기다. |

| CR-8 | 갑판의 내 상자는 꾹 눌러 다시 들 수 있다. 드는 순간 무게와 점수에서 빠지고, 다시 놓으면 새로 싣는 것으로 판정한다. 들고 갑판 밖에 놓으면 버린 것이 된다. |

끌어안기(S18)보다 꾹 누르기를 먼저 만든다. 되돌릴 수 없는 3초짜리 행동이 실수로 나가지 않게 하는 장치이므로, 덜 위험한 "내 상자 다시 들기"로 먼저 손에 익힌다.

## 쓰는 수치

<!--CONFIG: HOLD_TIME HOLD_TOLERANCE TARGET_RANGE INPUT_MIN_INTERVAL-->

| 키 | 값 | 뜻 |
| --- | --- | --- |
| `HOLD_TIME` | 0.5 | 꾹 누르기 시간(초) |
| `HOLD_TOLERANCE` | 0.1 | 서버가 꾹 누르기 시간을 확인할 때 봐주는 오차(초) |
| `TARGET_RANGE` | 6 | 들기, 다시 들기, 끌어안기의 대상이 되는 거리(스터드) |
| `INPUT_MIN_INTERVAL` | 0.1 | 같은 참가자의 버튼 요청 사이 최소 간격(초). 이보다 빨리 온 요청은 버린다 |

<!--/CONFIG-->

## 만들 것

클라이언트

1. **갑판에서의 대상 찾기.** 빈손이고 갑판 구역 안일 때, `TARGET_RANGE` 안에 있는 실린 상자 가운데 수평 거리가 가장 가까운 것이 대상이다. 2층이 있는 칸에서는 위 상자가 대상이다(GP-4). 대상에 테두리를 띄운다.
2. **누름을 둘로 가르기.** 버튼을 누른 시각을 적는다. 꾹 누르기를 시작할지 바로 톡으로 보낼지는 `InputRules`의 "누르는 순간"이 정한다(S03). 풀어 쓰면 아래와 같다.
   - 대상이 실린 상자가 아니면(손에 상자가 있다, 해변의 더미 앞이다, 갑판인데 가까운 상자가 없다) 누르는 순간 바로 `Tap`을 보낸다. S07과 같다.
   - 대상이 실린 상자면 그 상자 위에 고리가 차오르기 시작한다. 내 상자는 흰 고리다. 누르는 순간 `HoldBegin`을 보낸다.
   - `HOLD_TIME`이 되기 전에 떼면 고리를 지우고 톡 누르기로 처리한다(`Tap`을 보낸다).
   - `HOLD_TIME`을 채우면 `HoldEnd`를 "다 채움"으로 보낸다. 손을 떼기를 기다리지 않는다.
   - 누르는 동안 대상에서 `TARGET_RANGE` 밖으로 나가면 취소한다.
3. **톡 누르기의 힌트.** 갑판에서 빈손으로 톡 눌렀는데 서버가 "되찾을 것이 없다"고 알리면, 앞에 있는 대상 상자에 고리가 잠깐 비친다. "여기는 꾹 눌러야 한다"를 글 없이 알리는 것이다.
4. **버튼 그림.** 꾹 눌러야 하는 대상 앞에서는 버튼이 고리 모양이 된다.

서버

5. **`HoldBegin`.** 참가자와 상자 번호, 받은 시각을 적는다.
6. **`HoldEnd`.** 같은 상자의 `HoldBegin`이 있고, 그 사이가 `HOLD_TIME`에서 `HOLD_TOLERANCE`를 뺀 것보다 길어야 한다. 아니면 버린다. 서버는 잰 시간과 그 순간의 상황, 대상을 `InputRules`의 "꾹 누르기"에 넘기고, 돌아온 답(다시 들기, 끌어안기, 없음)을 실행한다.
7. **내 상자 다시 들기.** `HoldEnd`가 통과했고 그 상자의 주인이 누른 사람이면 다음을 본다: 단계가 `Loading`, 상태가 `Empty`, 갑판 구역 안, 상자까지 `TARGET_RANGE` 안. 모두 맞으면 실린 상자를 없애고 손에 붙인다. 상태는 `Carrying`. 무게와 점수를 다시 더한다.
8. **다시 놓기.** 손에 든 상자를 갑판에서 놓으면 S09의 판정을 처음부터 지난다. 갑판 밖에서 놓으면 사라진다. 따로 만들 것은 없고, S07의 놓기를 그대로 지나는지만 확인한다.
9. **처리 순서 4번을 채운다.** 갑판에서 빈손으로 온 `Tap`은 "되찾기 시도"다. 이 단계에서는 되찾을 것이 늘 없으므로 힌트 `Fx`만 보낸다. 진짜 되찾기는 S19에서 채운다.

## 하지 않는 것

- 남의 상자를 꾹 누르면 이 단계에서는 아무 일도 없다. 빨간 고리와 끌어안기는 S18에서 켠다.
- 꾹 누르기를 해변의 더미에 쓰지 않는다. 더미는 톡 누르기다.

## 완료 확인

- [ ] 갑판의 내 상자 앞에서 0.3초 누르고 떼면 들리지 않는다. 0.5초를 채우면 손을 떼지 않아도 들린다.
- [ ] 다시 드는 순간 무게가 그만큼 줄고, 머리 위 숫자가 줄고, 배가 떠오른다. 젖은 자국은 그대로다.
- [ ] 한계를 47로 고정하고 무게가 46일 때: 내 큰 상자를 들면 42가 되고, 다시 놓으면 46이 되어 버틴다.
- [ ] 같은 상황에서 내가 큰 상자를 들고 있는 동안 다른 사람이 중간 상자를 놓으면(44), 내가 다시 놓을 때(48) 가라앉고 내가 가라앉힌 사람이다.
- [ ] 다시 든 상자를 선착장에서 놓으면 사라진다. 점수는 빠진 채다.
- [ ] 첫 종 뒤에 내 상자를 들어 무게가 띠 아래로 내려가도 종은 계속 울린다.
- [ ] 갑판에서 빈손으로 톡 누르면 아무 일도 없고, 앞 상자에 고리가 한 번 비친다.
- [ ] 고리가 차는 중에 걸어서 멀어지면 취소된다.
- [ ] 2층이 있는 칸에서는 위 상자에 테두리가 뜨고, 위 상자를 치우면 아래 상자가 대상이 된다.
- [ ] DevTools로 `HoldBegin` 0.1초 뒤에 `HoldEnd`를 보내면 서버가 버린다.
- [ ] 폰에서 내 상자 앞을 지나가며 버튼을 스치듯 눌러도 들리지 않는다.
- [ ] 해변의 더미에서는 여전히 톡 한 번에 들린다.
- [ ] 서버를 켤 때 도는 규칙 시험(S03)이 전부 통과한다.

## 주의할 곳

- 고리는 클라이언트가 그리지만 시간의 확인은 서버가 한다. 고리가 다 찼는데 서버가 버리는 일이 통신이 느린 폰에서 잦으면 `HOLD_TOLERANCE`를 늘린다.
- 동작의 수를 세어 본다. 플레이어가 하는 일은 여전히 이동과 버튼 하나다. 누르는 방법이 둘이 되었을 뿐이고, 꾹 눌러야 하는 곳에서는 버튼이 고리로 바뀌어 알려 준다. 이 단계에서 버튼을 하나 더 만들고 싶어지면 만들지 않는다(KR-6, PR-3).
- 내 상자를 드는 것이 버리기를 피하는 수로 쓰인다. 든 상자는 끌어안을 수 없기 때문이다. 대신 든 동안에는 내 다른 상자를 되찾지 못한다(CR-7). 이 맞바꿈은 규칙이 의도한 것이므로 막지 않는다.
