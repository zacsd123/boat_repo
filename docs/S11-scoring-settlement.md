# S11. 점수와 정산

- **묶음**: 1묶음 · 사람끼리 하는 배 한 척
- **앞 단계**: S10
- **크기(어림)**: 보통
- **끝나면**: 배가 떠나거나 가라앉으면 각자 실은 만큼 점수가 나고, 가라앉힌 사람만 0이 되며, 12초 뒤 다음 배가 온다.

## 지킬 규칙

| 번호 | 규칙 |
| --- | --- |
| KR-1 | 한 문장 규칙: 보물을 배에 많이 실은 사람이 이기는데, 배를 가라앉힌 사람만 빈손이 된다. |
| KR-2 | 플레이어 규칙 1: 상자를 배에 놓으면 내 점수다. 큰 상자일수록 점수가 높고 무겁다. |
| SC-1 | 한 배의 점수는 그 배가 끝나는 순간(출항 또는 침몰) 갑판에 놓여 있는 내 상자 점수의 합이다. |
| SC-2 | 침몰하면 가라앉힌 사람은 그 배 0점이다. 나머지는 침몰 순간 갑판에 놓여 있던 자기 상자 점수를 전부 받는다. |
| SC-3 | 가라앉힌 사람이 잃는 것은 그 배의 점수뿐이다. 쌓아 둔 총점은 건드리지 않는다. |
| SC-6 | 이번 배 1등은 다음 배 동안 선장 모자를 쓴다(동점이면 모두). 그 배에서 점수를 낸 사람이 없으면 선장 모자는 없다. 표시일 뿐 효과는 없다. |
| SC-8 | 정산 때 이번 배 1등에게 팡파르가 울린다. |
| CR-11 | 라운드가 끝나면 손에 든 상자는 사라진다. |
| FL-6 | 정산(12초): 출항 또는 침몰 연출 3초, 각자의 상자가 점수로 바뀌는 5초, 다음 배가 들어오는 4초. 그동안 모두 자유롭게 움직인다. |
| UI-3 | 각 참가자 머리 위에 이번 배에 실은 점수가 숫자로 보인다. |
| UI-6 | 침몰하면 가라앉힌 사람에게 0이 뜨고, 나머지는 실은 만큼 받는 것이 보인다. |

## 쓰는 수치

| `CRATE_SCORE` | 작은 1, 중간 2, 큰 4, 황금 8 | 상자의 점수이자 무게 |

## 만들 것

1. **배 점수.** `ScoreService`가 참가자마다 갑판에 놓인 자기 상자의 점수를 더해 `BoatScore`에 쓴다. 더하는 것은 `ScoreRules`의 "배 점수"다(S03). 무게와 같은 때(실린 상자가 생기거나 사라질 때)에 다시 더한다.
2. **머리 위 숫자.** 캐릭터 머리 위에 `BoatScore`를 그 참가자의 색으로 띄운다. 숫자만 쓴다.
3. **점수 굳히기.** 라운드가 끝나는 순간(`Departing` 또는 `Sinking`에 들어갈 때) 모든 참가자의 `BoatScore`를 그 값으로 굳힌다. 침몰이면 가라앉힌 사람의 값을 0으로 바꾼다("배 점수"에 가라앉힌 참가자를 넘기면 그렇게 돌아온다). 이것도 단계를 바꾸는 같은 함수 안에서 한다.
4. **정산 12초.**
   - 처음 `SETTLE_SHOW_TIME`: 출항이면 배가 떠나고, 침몰이면 배가 가라앉는다.
   - 다음 `SETTLE_SCORE_TIME`: 갑판에 있던 상자가 주인에게 날아가 머리 위 숫자가 오른다. 가라앉힌 사람의 머리 위에는 큰 0이 뜬다.
   - 마지막 `SETTLE_ARRIVE_TIME`: 다음 배가 들어온다.
5. **이번 배 1등.** 굳힌 점수가 가장 높은 참가자(동점이면 모두, `ScoreRules`의 "앞선 사람들")에게 팡파르를 울리고, 다음 배 동안 선장 모자를 씌운다(`Hat` 속성). 가장 높은 점수가 0이면 팡파르도 모자도 없다.
6. **다음 배.** `Loading`에 들어가는 순간 `BoatScore`를 0으로 돌린다.
7. **1묶음에서의 총점.** 아직 총점은 없다(S23). 가라앉힌 사람이 잃는 것이 "그 배의 점수뿐"임(SC-3)은 지금 구조에서 저절로 선다. S23에서 총점을 붙일 때 다시 확인한다.

## 하지 않는 것

- 총점, 왕관, 최종 결과는 S23이다.
- 정산 때 진짜 한계를 보여 주지 않는다. "하나만 더 놓았으면 가라앉았다"를 보여 줄지는 기획 문서가 취향으로 남겨 둔 항목이고, 지금은 보여 주지 않는 쪽이다(BT-1). 바꾸려면 `01-rules.md`의 BT-1부터 고친다.
- 점수가 날아가는 연출을 다듬는 것은 S30이다. 이 단계에서는 숫자가 제때 제대로 바뀌는 것만 본다.

## 완료 확인

- [ ] 출항: 큰 상자 2개와 작은 상자 1개를 실은 사람의 점수가 9다.
- [ ] 침몰: 가라앉힌 사람은 0이다. 나머지는 가라앉는 순간 실려 있던 만큼을 그대로 받는다. 절반으로 깎이지 않는다.
- [ ] 가라앉힌 사람이 그 배에 큰 상자 3개를 실어 두었어도 0이다.
- [ ] 손에 든 채 끝난 상자는 누구의 점수도 아니다.
- [ ] 아무도 싣지 않은 배에서는 팡파르도 선장 모자도 없다.
- [ ] 1등이 둘이면 둘 다 선장 모자를 쓴다. 다음 배가 끝나면 새 1등에게 넘어간다.
- [ ] 정산 12초 동안 모두 걸어 다닐 수 있다.
- [ ] 가라앉힌 사람의 화면에서도, 남의 화면에서도 누가 0인지 보인다.
- [ ] 머리 위 숫자가 상자를 놓는 순간 바로 오른다.
- [ ] 정산 중에 새로 들어온 클라이언트가 오류 없이 다음 배부터 참가한다.
- [ ] 서버를 켤 때 도는 규칙 시험(S03)이 전부 통과한다.

## 주의할 곳

- 점수를 굳히는 시점은 "끝나는 순간"이다. 정산 연출이 도는 동안 사람이 나가거나 상자가 치워져도 굳힌 값은 변하지 않아야 한다.
- 가라앉힌 사람을 놀리는 정도는 취향이다. 이 단계에서는 큰 0만 띄운다.
- 원안의 "나머지는 절반"은 쓰지 않는다. 기획 문서가 "전부"로 정했고, 절반으로 되돌리면 실은 것이 없는 사람이 일부러 가라앉혀 남의 점수를 깎는 수가 다시 생긴다.
