## Script Sync (S01)

계획서와 실제가 달랐던 곳.

- **Beta Features에 Script Sync가 없다.** 계획서는 `File ⟩ Beta Features`에서 켜라고 했지만, 지금은 베타가 아니고 폴더 우클릭 메뉴에 바로 있다. 한국어판 메뉴는 `스크립트 동기화 ▶ 동기화 대상… / 동기화 중지 / 동기화 재개 / 디스크에서 보기`.
- **"동기화 대상…"은 고른 폴더 안에 같은 이름의 폴더를 만들어 잇는다.** 그래서 `Shared`, `Server`, `Client` 셋 모두 디스크의 `src` 폴더 자체를 골라야 `src/Shared` 등에 이어진다.
- **동기화가 오류로 멈춘 뒤 "동기화 재개"를 누르면 Studio 쪽이 디스크를 덮을 수 있다.** Studio 폴더가 비어 있을 때 두 번 디스크 스크립트가 모두 지워졌고 git으로 되살렸다. 재개 전에 양쪽 내용을 같게 맞춘다.
- MCP로 만든 Script는 RunContext가 기본값(Legacy)이라 `Main.legacy.luau`로 저장됐다. `RunContext = Server`로 바꿔 `Main.server.luau`로 되돌렸다.
- 비활성화된 스크립트는 동기화되지 않는다("지원되지 않는 속성"). 한때 `Main`이 비활성화되어 다시 켰다.
- 지금 상태: 세 폴더가 `src`에 이어져 있고 양방향으로 약 1초 안에 반영된다(S02에서 확인).

## S04 — 맵 (Studio에만 있다)

맵은 git에 없다. 백업은 Roblox에 게시한 판뿐이다. **이 파일을 쓸 때 사용자가 게시했는지는 확인하지 못했다.**

### 계획서와 다르게 한 것

- **원래 있던 Baseplate를 지웠다.** 윗면이 Y = 0(수면)이라 바다를 막았다.
- **기본 SpawnLocation을 해변 (0, 1.1, 22)로 옮기고 4 × 0.2 × 4로 줄였다.** S05에서 스폰 자리 8개로 나타나게 하기 전까지의 임시 자리다.
- **갑판 턱 위에 보이지 않는 벽(`Boat.LipGuards`, 높이 5)을 더했다.** 높이 1인 턱을 캐릭터가 점프 없이도 자동으로 올라 넘어갔다. 보이는 턱은 1 그대로이고 입구와 사다리 위는 비워 두었다.
- **화물칸 벽은 충돌 그룹 `CargoWall`(Default와 충돌)이다.** "캐릭터와만 충돌"은 캐릭터 충돌 그룹이 생기는 S05와 상자가 생기는 S07에서 마저 맞춘다. 실린 상자는 고정된 채 놓이므로 지금도 벽에 막히지 않는다.
- **맵 둘레에 보이지 않는 벽(`Sea.Bounds`)을 세웠다.** "맵 밖으로 떨어지는 곳이 없다"를 지키려고.
- 단상은 계획서대로 해변 서쪽 (−16, 1.5, 24)에 블록 하나만 두었다(쓰는 것은 S23).
