# 규칙 기준서

개발하는 동안 "규칙"은 이 파일을 말한다. 기획 문서 「배 가라앉히지 마 — 기획 다듬기」 2번(다듬은 규칙)을 한 줄에 규칙 하나씩 옮기고 번호를 붙였다. 2026년 10월 9일에 확인한 문서 내용이 기준이고, 두 번째 피드백의 두 가지(인원별 한계 범위, 황금 상자 4.5초)가 들어가 있다.

## 읽는 법

- 번호의 앞 두 글자는 묶음이다. 단계 파일은 이 번호로 규칙을 가리킨다.
- KR부터 VR까지는 기획 문서의 규칙이다. 뜻을 바꾸지 않고 옮겼다.
- PR은 기획 요청서의 "지켜야 할 성질"이다. 코드로 구현하는 것이 아니라 테스트 단계에서 확인한다.
- GP는 기획 문서에 없어서 이 계획에서 정한 것이다. 규칙을 만들려면 정해야 하는데 문서가 말하지 않은 곳만 채웠다. 마음에 들지 않으면 여기부터 바꾼다.
- 숫자는 되도록 `02-config.md`의 키로 가리킨다. 이 파일에 적힌 숫자와 수치 파일이 다르면 수치 파일이 맞다.

## 규칙을 바꾸고 싶을 때

만들다 보면 규칙을 바꾸고 싶어진다. 그때는 코드부터 고치지 않는다.

1. 이 파일의 해당 줄을 고친다. 새 규칙이면 번호를 새로 준다. 지운 번호는 다시 쓰지 않는다.
2. 숫자만 바뀌면 `02-config.md`의 값만 고친다. 규칙 문장은 그대로 둔다.
3. S03의 시험 표에서 그 규칙 번호가 달린 시험을 고친다. 없으면 더한다. 코드보다 시험을 먼저 고친다.
4. `build.py`를 돌려 그 규칙이 걸린 단계를 `04-traceability.md`에서 찾는다.
5. 코드를 고치고, 그 단계들의 "완료 확인"을 다시 돌린다.
6. 기획 문서에도 같은 내용을 반영한다.

## 핵심 (KR)

| 번호 | 규칙 |
| --- | --- |
| KR-1 | 한 문장 규칙: 보물을 배에 많이 실은 사람이 이기는데, 배를 가라앉힌 사람만 빈손이 된다. |
| KR-2 | 플레이어 규칙 1: 상자를 배에 놓으면 내 점수다. 큰 상자일수록 점수가 높고 무겁다. |
| KR-3 | 플레이어 규칙 2: 물이 선체의 빨간 띠에 닿으면 종이 울리기 시작하고, 그때부터 배는 언제든 가라앉을 수 있다. 가라앉으면 마지막 상자를 놓은 사람만 그 배에서 0점이다. |
| KR-4 | 플레이어 규칙 3: 남의 상자는 꾹 눌러 끌어안고 바다로 뛰어들어 버릴 수 있다. 주인이 옆에서 버튼을 누르면 상자는 남고 나만 빠진다. |
| KR-5 | 플레이어 규칙 4: 종이 세 번 울리면 배가 떠나고, 그때 배에 놓여 있는 만큼이 점수다. |
| KR-6 | 조작은 이동과 버튼 하나다. 버튼을 누르는 방법은 톡 누르기와 꾹 누르기 둘이다. |

## 흐름 (FL)

| 번호 | 규칙 |
| --- | --- |
| FL-1 | 접속하면 2초 안에 해변의 상자 더미 옆에 나타난다. 메뉴, 대기실, 준비 버튼이 없다. |
| FL-2 | 라운드가 진행 중이면 접속하자마자 상자를 들 수 있다. 정산 중이면 최대 12초, 최종 결과 중이면 최대 25초를 자유롭게 돌아다니며 기다린다. |
| FL-3 | 판 시작(5초): 첫 배가 선착장에 들어온다. |
| FL-4 | 라운드 시작: 뱃고동이 울리고 상자 더미가 열린다. 각자 있던 자리에서 시작한다. 더미는 라운드 동안에만 열려 있다. |
| FL-5 | 라운드는 셋째 종의 출항이나 침몰로 끝난다. 보통 26\~34초이고 가장 길어도 54초다. |
| FL-6 | 정산(12초): 출항 또는 침몰 연출 3초, 각자의 상자가 점수로 바뀌는 5초, 다음 배가 들어오는 4초. 그동안 모두 자유롭게 움직인다. |
| FL-7 | 한 판은 배 8척이다. 8번째 배는 금빛 돛을 달고 온다. |
| FL-8 | 최종 결과(20초): 8번째 배는 정산 없이 바로 최종 결과로 넘어간다. 연출 3초, 마지막 배 점수 5초, 해변의 단상에 1\~3등이 서고 전원의 총점이 보이는 12초. |
| FL-9 | 최종 결과가 끝나면 총점이 0으로 돌아가고 판 시작부터 다시 한다. 사람이 한 명이라도 있으면 서버는 판을 쉬지 않고 이어 돌린다. |

## 점수 (SC)

| 번호 | 규칙 |
| --- | --- |
| SC-1 | 한 배의 점수는 그 배가 끝나는 순간(출항 또는 침몰) 갑판에 놓여 있는 내 상자 점수의 합이다. |
| SC-2 | 침몰하면 가라앉힌 사람은 그 배 0점이다. 나머지는 침몰 순간 갑판에 놓여 있던 자기 상자 점수를 전부 받는다. |
| SC-3 | 가라앉힌 사람이 잃는 것은 그 배의 점수뿐이다. 쌓아 둔 총점은 건드리지 않는다. |
| SC-4 | 총점은 배 점수의 합이다. 8번째 배의 점수는 2배로 더한다. |
| SC-5 | 최종 순위는 총점 순이다. 동점이면 8번째 배 점수가 높은 쪽이 앞서고, 그래도 같으면 공동 순위다. |
| SC-6 | 이번 배 1등은 다음 배 동안 선장 모자를 쓴다(동점이면 모두). 그 배에서 점수를 낸 사람이 없으면 선장 모자는 없다. 표시일 뿐 효과는 없다. |
| SC-7 | 총점 1등은 왕관을 쓴다(동점이면 모두). 표시일 뿐 효과는 없다. |
| SC-8 | 정산 때 이번 배 1등에게 팡파르가 울린다. |

## 배와 한계 (BT)

| 번호 | 규칙 |
| --- | --- |
| BT-1 | 숨은 한계는 인원별 한계 범위 안의 정수 하나다. 라운드마다 고르게 무작위로 뽑고 누구에게도 보여 주지 않는다. |
| BT-2 | 배의 무게는 갑판에 놓인 상자 무게의 합이다. 손에 든 상자와 캐릭터는 무게가 아니다. |
| BT-3 | 수위는 무게에 정비례한다. 무게가 한계 범위의 아래 끝일 때 물이 빨간 띠 아래 끝에, 위 끝일 때 띠 위 끝인 갑판 턱에 닿는다. |
| BT-4 | 물이 빨간 띠에 닿아 있는 동안 배가 삐걱거린다. 소리는 띠 안에서 수위가 높을수록 커지고, 진짜 한계와는 무관하다. |
| BT-5 | 이번 라운드에 닿았던 가장 높은 수위는 선체에 젖은 자국으로 남는다. 그 아래까지는 이미 버틴 무게다. |
| BT-6 | 침몰 판정은 상자가 갑판에 놓이는 순간에만 한다. 놓은 뒤 무게가 한계보다 크면 즉시 침몰하고, 그 상자를 놓은 참가자가 가라앉힌 사람이다. 무게가 한계와 같으면 버틴다. |
| BT-7 | 동시에 놓인 상자는 서버에 도착한 순서로 하나씩 판정한다. 침몰을 일으킨 상자보다 늦게 도착한 놓기는 없던 일이 된다. |
| BT-8 | 침몰하면 라운드는 그 순간 끝난다. |
| BT-9 | 갑판은 끝에서 끝까지 걸어서 1.5초다. 갑판에 빈손으로 있는 주인은 3초 안에 자기 상자 어디든 닿는다. |

## 종과 출항 (BL)

| 번호 | 규칙 |
| --- | --- |
| BL-1 | 첫 종은 배의 무게가 이번 라운드에 처음으로 한계 범위의 아래 끝에 닿는 순간 울린다. 40초까지 닿지 않으면 40초에 울린다. |
| BL-2 | 둘째 종은 첫 종 3\~7초 뒤, 셋째 종은 둘째 종 3\~7초 뒤다. 두 간격은 라운드마다 따로 고르게 무작위로 뽑는다. 남은 시간은 어디에도 표시하지 않는다. |
| BL-3 | 한 번 울리기 시작한 종은 멈추지 않는다. 상자가 버려져 물이 띠 아래로 내려가도 그대로 간다. |
| BL-4 | 셋째 종이 울리는 순간 출항이다. 그보다 늦게 도착한 놓기는 없던 일이 된다. |
| BL-5 | 첫 종 전에는 배가 가라앉지 않는다. 물을 띠에 닿게 한 바로 그 상자는 배를 가라앉힐 수 있다. |

| 번호 | 규칙 |
| --- | --- |

| CR-5 | 갑판에서 놓으면 실린 것이다. 내 색 리본이 붙고 무게와 내 점수에 더해진다. 갑판 자리는 모자라지 않는다(쌓인다). |

| CR-8 | 갑판의 내 상자는 꾹 눌러 다시 들 수 있다. 드는 순간 무게와 점수에서 빠지고, 다시 놓으면 새로 싣는 것으로 판정한다. 들고 갑판 밖에 놓으면 버린 것이 된다. |
| CR-9 | 상자를 든 채 물에 들어가면 놓친 것으로 친다. 일반 상자는 사라진다. |
| CR-10 | 같은 상자에 둘이 동시에 버튼을 누르면 서버에 먼저 도착한 쪽만 성공한다. |
| CR-11 | 라운드가 끝나면 손에 든 상자는 사라진다. |

| 번호 | 규칙 |
| --- | --- |
| IN-1 | 버튼의 대상은 가장 가까운 상자 하나이고, 대상에는 테두리가 뜬다. |
| IN-2 | 손에 상자가 있으면 톡 누르기는 놓기다. |
| IN-3 | 빈손으로 해변의 더미나 황금 상자 앞에 있으면 톡 누르기는 들기다. |
| IN-4 | 빈손으로 갑판에 있으면 톡 누르기는 되찾기다. 끌어안긴 내 상자가 손 닿는 거리에 없으면 아무 일도 일어나지 않고, 앞에 있는 상자에 고리가 잠깐 비쳐 꾹 눌러야 한다는 것을 알려 준다. |
| IN-5 | 빈손으로 갑판의 상자 앞에서 0.5초 꾹 누르면 남의 상자는 끌어안기, 내 상자는 다시 들기다. |
| IN-6 | 꾹 누르는 동안 대상 상자에 고리가 차오른다. 남의 상자는 빨간 고리, 내 상자는 흰 고리다. 다 차기 전에 떼면 취소된다. |
| IN-7 | 버튼의 그림은 지금 누르면 일어날 일에 맞춰 바뀐다. 꾹 눌러야 하는 대상 앞에서는 고리 모양이 된다. |

## 끌어안기 (HG)

| 번호 | 규칙 |
| --- | --- |
| HG-1 | 끌어안을 수 있는 것은 갑판에 놓인 남의 상자뿐이다. |
| HG-2 | 한 상자는 한 번에 한 사람만 끌어안는다. 먼저 도착한 쪽이 성공한다. |
| HG-3 | 꾹 누르기가 끝나면 끌어안기가 시작된다. 그때부터 3초 동안은 취소도 다른 행동도 못 한다. |
| HG-4 | 끌어안긴 상자는 3초가 찰 때까지 갑판에 있는 것으로 친다. 무게와 주인 점수에 그대로 들어간다. |
| HG-5 | 3초가 차면 상자와 함께 바다로 뛰어든다. 상자는 사라지고 버린 사람은 물에 빠진다. |
| HG-6 | 끌어안기가 시작되는 순간 주인의 화면에 소리와 방향 화살표가 뜬다. |
| HG-7 | 라운드가 끝나면(출항 또는 침몰) 진행 중이던 끌어안기는 무효다. 그 상자는 주인 점수로 정산된다. |
| HG-8 | 주인이 나가면 그 상자와 함께 끌어안기도 끝나고, 끌어안던 사람은 갑판에 남는다. |

## 되찾기 (RC)

| RC-4 | 주인이 상자를 들고 있거나, 물에 있거나, 자기도 끌어안는 중이거나, 멀리 있으면 되찾지 못한다. |

## 물과 캐릭터 (WT)

| 번호 | 규칙 |
| --- | --- |
| WT-1 | 물에 빠진 사람이 나오는 데는 사다리로 갑판까지 4.5초, 해변까지 4.5초가 걸린다. |
| WT-2 | 물에서는 아무것도 들 수 없다. |

## 계획에서 정한 것 (GP)

기획 문서가 말하지 않은 곳이다. 규칙을 바꾼 것이 아니라 빈 곳을 채운 것이고, 각 줄에 그렇게 정한 이유를 적었다.

| 번호 | 규칙 |
| --- | --- |
| GP-1 | 점프를 끈다. 조작은 이동과 버튼 하나이고, 점프가 있으면 갑판 턱이나 선착장을 뛰어넘는 지름길이 생겨 걷는 시간이 깨진다. |
| GP-2 | 캐릭터 초기화(리셋)를 끈다. 캐릭터는 죽지 않는다. 리셋이 되면 물에서 나오는 시간을 건너뛸 수 있다. |
| GP-3 | 실린 상자는 갑판 가운데 화물칸의 칸에 놓인다. 놓는 사람에게 가장 가까운 빈 칸에 들어가고, 통로에는 놓이지 않는다. 캐릭터는 화물칸 안으로 들어가지 못한다. 상자로 길을 막거나 캐릭터가 상자와 겹치는 일이 없게 하려는 것이다. |
| GP-4 | 화물칸의 칸이 다 차면 가장 가까운 칸의 2층에 쌓는다. 2층이 있는 칸에서는 위 상자가 먼저 대상이 된다. |
| GP-5 | 들기, 다시 들기, 끌어안기의 대상이 되는 거리는 6스터드(캐릭터 하나 반 너비)다. |
| GP-6 | 출항하면 갑판 위에 있던 사람은 선착장에 내려 준다. 물에 빠뜨리지 않는다. 끝까지 지키던 사람이 다음 배에서 손해 보지 않게 하려는 것이다. |
| GP-7 | 끌어안긴 상자는 주인도 다시 들 수 없다. 주인이 할 수 있는 것은 되찾기다. |
| GP-8 | 끌어안기나 되찾기로 물에 빠지는 사람은 배 옆의 정해진 물 자리에 떨어진다. 물속 속도와 사다리 오르는 시간으로 나오는 데 걸리는 4.5초를 맞춘다. |

## 어기기 쉬운 곳

만들다가 무심코 규칙과 다르게 만들기 쉬운 곳이다. 대부분 S03의 시험이 잡아 주지만, 단계를 시작할 때 한 번씩 읽는다.

1. **무게가 한계와 같으면 버틴다**(BT-6). 비교는 "크면"이다. "크거나 같으면"이 아니다.
2. **침몰 판정은 놓는 순간에만 한다**(BT-6). 시간이 흐르거나 상자가 빠질 때는 판정하지 않는다.
3. **물을 띠에 닿게 한 바로 그 상자도 배를 가라앉힐 수 있다**(BL-5). 그때는 첫 종과 침몰이 같은 순간이다.
4. **첫 종의 조건은 "아래 끝 이상"이다**(BL-1). 침몰의 "한계보다 크면"과 헷갈리지 않는다.
5. **손에 든 상자는 무게도 점수도 아니다**(BT-2, CR-7). 갑판 위에 서 있어도 마찬가지다.
6. **끌어안긴 상자는 3초가 찰 때까지 무게와 점수에 남는다**(HG-4).
7. **라운드가 끝나면 진행 중이던 끌어안기는 무효다**(HG-7). 그 상자는 주인 점수로 정산된다.
8. **첫 종은 한 라운드에 한 번만 울리고, 울리기 시작한 종은 멈추지 않는다**(BL-1, BL-3).
9. **숨은 한계와 종 간격은 서버 밖으로 내보내지 않는다**(BT-1, BL-2). 남은 시간을 내비치는 표시도 만들지 않는다.
10. **침몰해도 나머지는 전부 받는다. 가라앉힌 사람은 그 배 점수만 0이고 총점은 그대로다**(SC-2, SC-3).
11. **톡 누르기로는 끌어안기도 내 상자 다시 들기도 시작되지 않는다**(IN-4, IN-5).
12. **상자를 든 채 톡 누르면 어디서든 놓기다**(IN-2). 갑판 밖이면 상자가 사라진다(CR-6). 든 동안에는 되찾지 못한다(CR-7).
13. **다시 든 내 상자를 다시 놓으면 새로 싣는 판정을 한다**(CR-8). 침몰도 일어날 수 있다.
14. **P는 라운드 시작 순간에 정해진다**(JN-5). 도중에 사람이 들어오거나 나가도 그 라운드의 한계 범위와 빨간 띠는 바뀌지 않는다.
15. **젖은 자국은 내려가지 않는다**(BT-5). 상자가 버려지거나 사람이 나가 무게가 줄어도 그대로다.
16. **황금 상자는 큰 상자와 같은 속도로 나른다**(GD-2). 갑판 밖에 놓으면 남고(GD-3), 든 채 물에 빠지면 바위로 돌아간다(GD-4).
17. **한계 범위는 공식이 아니라 인원별 표에서 읽는다**(BT-1, GP-12).
18. **글자로 설명하지 않는다**(UI-5, PR-2, PR-9). 버튼, 경고, 결과 모두 그림과 소리와 숫자로 한다.
19. **봇도 사람과 같은 판정을 지난다**(PL-4). 봇용 지름길을 만들지 않는다.
