# S05. 캐릭터 기본

- **묶음**: 준비
- **앞 단계**: S04
- **크기(어림)**: 작음
- **끝나면**: 캐릭터끼리 통과하고, 점프와 캐릭터 초기화가 꺼져 있고, 접속하면 더미 옆에 나타나며, 참가자마다 슬롯과 색이 있다.

## 지킬 규칙

| 번호 | 규칙 |
| --- | --- |
| KR-6 | 조작은 이동과 버튼 하나다. 버튼을 누르는 방법은 톡 누르기와 꾹 누르기 둘이다. |

| GP-1 | 점프를 끈다. 조작은 이동과 버튼 하나이고, 점프가 있으면 갑판 턱이나 선착장을 뛰어넘는 지름길이 생겨 걷는 시간이 깨진다. |
| GP-2 | 캐릭터 초기화(리셋)를 끈다. 캐릭터는 죽지 않는다. 리셋이 되면 물에서 나오는 시간을 건너뛸 수 있다. |
| GP-14 | 참가자 색은 정해 둔 8색에서 빈 자리 순서로 준다. 봇도 같은 색 목록을 쓴다. |

## 만들 것

1. **캐릭터끼리 통과.** 충돌 그룹을 하나 만들고 그 그룹이 자기 자신과 충돌하지 않게 한다. 캐릭터가 생길 때 모든 파트를 그 그룹에 넣는다. 나중에 붙는 파트(장신구)도 들어가도록 캐릭터에 파트가 더해질 때마다 넣는다. S04에서 세운 화물칸 벽은 이 그룹과만 충돌하게 맞춘다.
2. **점프 끄기.** 점프 높이를 0으로 하고 Humanoid의 점프 상태도 끈다. 폰의 자동 점프도 끈다. 폰 화면에서 점프 버튼이 사라졌는지 눈으로 확인한다.
3. **캐릭터 초기화 끄기.** 메뉴의 캐릭터 초기화 버튼이 눌리지 않게 한다.
4. **걷는 속도.** 빈손일 때 `WALK_SPEED`.
5. **나타나는 자리.** S04의 스폰 자리 8개 중 비어 있는 곳.
6. **안전망.** 캐릭터는 죽지 않아야 하지만, 죽거나 맵 밖으로 나가면 더미 옆에 다시 나타나게 한다.
7. **참가자 기록의 첫 모양.** `ParticipantService`가 접속한 사람마다 `ReplicatedStorage.Participants`에 폴더 하나를 만든다. 슬롯(1\~8)은 비어 있는 가장 작은 번호, 색은 `PARTICIPANT_COLORS`의 그 번호. 나가면 폴더를 지운다. 상태 속성은 `Empty`로 시작한다.

## 하지 않는 것

- 달리기, 구르기, 밀치기 같은 동작을 더하지 않는다. 동작은 이동과 버튼 하나다.
- 사람이 나갈 때 상자를 치우는 일은 S13에서 한다.

## 완료 확인

- [ ] 클라이언트 둘이 마주 걸으면 서로 통과한다. 갑판 통로와 배다리처럼 좁은 곳에서도 막히지 않는다.
- [ ] 캐릭터는 바닥, 배, 갑판 턱, 화물칸 벽에는 막힌다(통과는 캐릭터끼리만이다).
- [ ] 폰 화면에 이동 스틱만 있고 점프 버튼이 없다. PC에서 스페이스를 눌러도 뛰지 않는다.
- [ ] 점프 없이 해변, 선착장, 배다리, 갑판, 해안 경사를 모두 걸어 다닐 수 있다. 턱에 걸려 멈추는 곳이 없다.
- [ ] 메뉴에서 캐릭터 초기화가 눌리지 않는다.
- [ ] 클라이언트 4개를 동시에 띄우면 네 캐릭터가 더미 호 뒤에 서로 겹치지 않게 나타난다.
- [ ] 참가자 폴더 넷에 슬롯 1\~4와 서로 다른 색이 있다. 2번 클라이언트를 껐다 다시 켜면 슬롯 2를 다시 받는다.
- [ ] 물에 걸어 들어가도 죽지 않는다.
- [ ] 클라이언트를 띄우면 화면이 보인 뒤 2초 안에 캐릭터가 더미 옆에 서 있다. 그 사이에 메뉴나 버튼, 안내가 뜨지 않는다.

## 주의할 곳

- 점프를 끄면 지형의 작은 턱이 벽이 된다. S04의 맵을 이 단계에서 한 번 더 걸어 본다.
- 충돌 그룹은 캐릭터끼리만 끈다. 상자와 캐릭터, 배와 캐릭터는 그대로 둔다.
- 통과는 WT-5가 요구한 것이다. 좁은 갑판에서 길을 막거나 밀어 떨어뜨리는 플레이를 없애려는 규칙이므로, 연출 때문에 다시 켜지 않는다.
