# 규칙 추적표

모든 규칙이 어느 단계에서 구현되거나 확인되는지를 모은 표다. `build.py`가 단계 파일의 "지킬 규칙" 절에서 뽑아 만든다. 손으로 고치지 않는다. 고치려면 단계 파일의 규칙 목록을 고치고 `build.py`를 돌린다.

쓰는 때는 둘이다. 단계를 끝낼 때 그 단계에 걸린 규칙을 다시 읽는다. 공개 전(S30)에 이 표를 위에서부터 한 줄씩 다시 확인한다.
