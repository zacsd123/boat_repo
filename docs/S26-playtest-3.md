# S26. 테스트 3과 조정

- **묶음**: 3묶음 · 황금 상자, 판, 봇 하나
- **앞 단계**: S25
- **크기(어림)**: 보통
- **끝나면**: 사람 둘에 봇 둘인 판, 혼자서 봇 셋과 하는 판, 도중에 사람이 들어오는 판을 해 본 기록이 있고, 그 기록으로 판의 구조와 황금 상자를 정했다.

## 준비

1. **기록.** S22와 S23에서 넓힌 기록(황금 상자, 총점, 판의 길이)이 찍히는지 한 판을 돌려 확인한다.
2. **사람.** 3명이면 된다. 판마다 들어와 있는 사람 수를 바꾼다.
3. **설명하지 않는다.** 2배도, 황금 상자도, 봇도 말해 주지 않는다.

## 진행

| 판 | 구성 | 보려는 것 |
| --- | --- | --- |
| 1, 2 | 사람 2 + 봇 2 | 둘이서 하는 판이 굴러가는가. 앞선 사람이 상대만 막는가 |
| 3 | 사람 3 + 봇 1. 네 번째 배쯤에 한 사람이 나갔다가 다른 사람이 들어온다 | 도중 참가와 이탈 |
| 4 | 사람 1 + 봇 3 (만든 사람 말고 다른 사람이 혼자) | 혼자서 몇 척을 버티는가 |
| 5 | 사람 3 + 봇 1 | 판의 길이, 황금 상자, 마지막 배 |

다섯 판이면 40척이다. 한 시간쯤 걸린다.

## 볼 것

| 무엇 | 어디서 보나 | 견줄 값 |
| --- | --- | --- |
| 1. 2명 판에서 앞선 사람이 싣기를 멈추고 상대 상자만 노리는가, 그렇게 이기는가 | 옆에서 본다, 기록의 끌어안기 횟수 | 두 판 가운데 한 판도 그렇게 끝나지 않아야 한다 |
| 2. 황금 상자를 집은 배의 비율 | 기록 | 넷 중 한 척 이상 |
| 3. 황금 상자를 누가 집는가 | 기록 | 그 배에서 점수가 낮은 사람 쪽 |
| 4. 황금 상자가 갑판에 닿은 때와 그때의 무게 | 기록 | 큰 상자를 하나 더 가져온 사람과 같은 때. 4명 판이면 무게 48에서 56 사이 |
| 5. 황금 상자를 놓은 배가 가라앉은 비율 | 기록 | 열에 넷에서 여섯. 열에 일곱을 넘으면 너무 위험하다 |
| 6. 마지막 배가 우승자를 바꿨는가 | 기록의 총점 | 다섯 판 가운데 한두 판 |
| 7. 도중에 들어온 사람이 남은 배에서 무엇을 하는가 | 옆에서 본다, 묻는다 | 손을 놓지 않고 싣는다 |
| 8. 혼자서 봇과 몇 척을 하다 그만두고 싶어지는가 | 4번째 판, 묻는다 | 한 판(8척)은 채운다 |
| 9. 판의 길이 | 기록 | 5분에서 7분. 가장 길어도 9분 |
| 10. 2배를 알아챘는가 | 묻는다: "마지막 배는 뭐가 달랐어?" | 금빛 돛이나 금색 숫자를 말한다 |
| 11. 봇을 봇으로 알아봤는가 | 묻는다 | 바로 알아본다 |

## 결과에 따른 결정

| 본 것 | 뜻 | 바꿀 것 |
| --- | --- | --- |
| 2명 판 두 판 가운데 한 판 이상을 "상대만 막기"로 이긴다 | 2명 판이 버리기 싸움이 된다 | S27의 방해꾼 봇을 먼저 만들어 2명 판에 넣는다. 방해꾼은 이번 배 1등을 노리므로 앞선 사람이 싣기를 멈추면 표적이 된다 |
| 황금 상자를 집은 배가 넷 가운데 한 척에 못 미친다 | 집을 이유가 약하다 | 바위를 선착장 경사로 입구 쪽으로 옮긴다. 입구까지의 거리를 11.5에서 6으로 줄이면 가고 오는 길이 합쳐 0.9초쯤 줄어, 남들의 큰 상자(27초)보다 앞선 26초쯤에 닿는다. 그때는 황금 상자의 4.5초가 4.0초가 되므로 `01-rules.md`의 GD-2도 함께 고친다 |
| 황금 상자를 놓은 배가 열에 일곱을 넘게 가라앉는다 | 황금 상자가 침몰 단추다 | `LIMIT_RANGE`의 위 끝을 올린다(S16의 표를 본다) |
| 마지막 배가 다섯 판 모두에서 우승자를 바꾼다 | 앞의 일곱 척이 의미가 없다 | `LAST_BOAT_MULTIPLIER`를 1.5로 |
| 마지막 배 전의 1등이 다섯 판 모두 우승하고, 뒤처진 사람이 손을 놓는다 | 뒤집을 길이 안 보인다 | 2배를 알리는 그림을 키운다. 그래도 같으면 `BOATS_PER_MATCH`를 6으로 줄여 차이가 덜 벌어지게 한다 |
| 판이 자주 7분을 넘는다 | 길다 | `BOATS_PER_MATCH`를 7로 |
| 판이 5분에 못 미친다 | 짧다 | `BOATS_PER_MATCH`를 9로 |
| 도중에 들어온 사람이 다섯 판 가운데 두 판 이상 우승한다 | 늦게 올수록 이득이다 | `JOIN_SCORE_OFFSET`을 10으로 |
| 봇이 섞인 판이 사람끼리의 판보다 눈에 띄게 밋밋하다 | 봇이 자리를 너무 차지한다 | `BOT_FILL_TO`를 3으로. 범위는 3명 값이 쓰인다 |
| 2배를 아무도 알아채지 못한다 | 그림이 약하다 | 금빛 돛과 금색 숫자를 키운다. 글로 알리지 않는다 |
| 혼자 하는 사람이 네 척 안에 그만두고 싶어 한다 | 혼자 하는 판이 너무 얕다 | S27을 앞당긴다. 봇이 버리기와 지키기를 보여 주면 혼자서도 대응할 일이 생긴다 |

## 넘어가는 조건

- [ ] 다섯 판(40척)의 기록이 있다.
- [ ] 2명 판이 "상대만 막기"로 끝나지 않는다. 그렇게 끝났다면 방해꾼 봇을 넣고 두 판을 다시 했다.
- [ ] 판의 길이가 5분에서 7분 사이다.
- [ ] 황금 상자가 넷 중 한 척 이상에서 집히고, 놓은 배의 침몰이 열에 일곱을 넘지 않는다.
- [ ] 도중에 들어온 사람이 오류 없이 꼴찌 총점에서 시작했고, 남은 배를 끝까지 했다.
- [ ] 혼자 한 사람이 한 판을 채웠다.
- [ ] 바꾼 수치를 `02-config.md`와 기획 문서에 적었고, S22부터 S25까지의 완료 확인을 다시 돌렸다.

여기까지 차면 첫 버전의 규칙은 모두 서 있다. 4묶음은 그 위에 얹는 것이다.

## 주의할 곳

- 황금 상자의 값(견줄 값 4번)은 두 번째 피드백이 짚은 곳이다. 기록에서 "황금 상자가 닿은 때"와 "그 배에서 종 뒤에 놓인 다른 상자들의 때"를 나란히 놓고, 황금 상자가 늘 뒤에 놓이는지 본다. 늘 뒤라면 바위를 옮길 근거다.
- 혼자 하는 판은 기획 문서도 얕다고 적었다. 고치려는 것이 아니라 "한 판은 버티는가"만 본다. 사람이 들어올 때까지 붙잡아 두는 것이 봇의 일이다.
- 2명 판의 문제는 기획 문서가 풀지 못했다고 적은 약점이다. 방해꾼 봇으로 누그러뜨릴 뿐이고, 그래도 남으면 남는다고 적어 둔다.
