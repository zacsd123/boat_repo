## 만들 것

1. **배 한 척의 기록.** `Telemetry`가 라운드가 끝나는 순간 아래를 한 줄로 남긴다.

   | 항목 | 내용 |
   | --- | --- |
   | 언제 | 서버 시각, 배 번호 |
   | 인원 | P, 사람 수, 봇 수 |
   | 한계 | 범위의 양 끝, 뽑힌 숨은 한계 |
   | 종 | 첫 종 시각, 첫 종이 띠 때문인지 상한 때문인지, 뽑힌 간격 둘 |
   | 끝 | 끝난 시각, 출항인지 침몰인지, 가라앉힌 슬롯 |
   | 무게 | 끝난 순간의 무게, 최고 무게 |
   | 종 뒤의 상자 | 첫 종이 울린 뒤에 해변에서 새로 들어 와 놓은 상자의 수("하나 더"의 수). 종류별 |
   | 참가자마다 | 점수, 실은 상자 수, 첫 종 뒤에 가만히 서 있던 시간, 물에 빠진 횟수 |

2. **"가만히 서 있던 시간"의 정의.** 첫 종부터 라운드 끝까지, 상태가 `Empty`이고 1초 동안 `IDLE_MOVE_THRESHOLD`도 움직이지 않은 시간의 합. 상자를 들고 망설이는 시간과 물속에 있는 시간은 넣지 않는다.
3. **요약.** 지금까지의 모든 배에 대해 계산한다.
   - 침몰한 척의 비율
   - 라운드 길이의 평균, 첫 종까지 걸린 시간의 평균
   - 배마다 "하나 더"의 수 평균
   - 첫 종 뒤 가만히 서 있던 시간의 참가자 평균과 최댓값
   - 첫 종이 상한 때문에 울린 척의 수
4. **꺼내 보는 길 둘.**
   - 서버 출력에 한 척마다 쉼표로 나눈 한 줄을 찍는다. 게시한 서버에서는 개발자 콘솔의 서버 로그로 본다. 서버 로그는 게임 주인만 볼 수 있다.
   - 게임 주인에게만 보이는 요약 창. 주인의 계정 번호와 같은 사람에게만 값을 보낸다.
5. **나중에 더할 자리.** 2묶음에서 끌어안기 시도, 성공, 되찾기, 다시 들기의 횟수를 더한다(S21). 3묶음에서 황금 상자를 든 슬롯과 놓은 무게와 결과, 총점을 더한다(S26). 지금은 칸만 비워 둔다.
6. **기록 초기화 명령.** 테스트를 시작하기 직전에 지금까지의 기록을 비운다.

## 하지 않는 것

- 기록을 저장소에 남기지 않는다. 서버가 닫히면 사라진다. 테스트가 끝나면 서버 로그를 복사해 둔다.
- 외부 분석 도구를 붙이지 않는다.
- 기록 때문에 판정 순서를 바꾸지 않는다. 기록은 판정 함수가 끝난 뒤에 쓴다.

- [ ] 기록을 켠 채 S09와 S10의 완료 확인을 다시 돌려도 결과가 같다.

## 주의할 곳

- 숨은 한계가 들어간 기록은 서버에만 있어야 한다. 요약 창에는 한계를 넣지 않는다. 주인도 플레이하면서 테스트하기 때문이다.
- "하나 더"의 수는 놓은 시각이 아니라 든 시각으로 가른다. 첫 종 전에 들어서 첫 종 뒤에 놓은 상자는 세 번째 왕복의 상자이지 "하나 더"가 아니다. 그래서 상자를 드는 순간의 시각을 상자에 적어 둔다.
- 4명이 계산대로 움직이면 "하나 더"는 배마다 2개, 모두 욕심을 내면 4개다. S16이 이 두 값과 견준다.
