# S21. 친구 테스트 2와 조정

- **묶음**: 2묶음 · 끌어안기와 되찾기
- **앞 단계**: S20
- **크기(어림)**: 보통
- **끝나면**: 버리기가 판을 더 재미있게 하는지 사람과 해 본 기록이 있고, 그 기록으로 버리기의 값(꾹 누르기, 끌어안기, 물)을 정했거나 버리기를 빼기로 했다.

버리기는 이 게임의 구별점이면서 가장 큰 위험이다. "내 것만 계속 버려진다"는 불쾌감이 재미를 이기면 고친 것이 아니다. 이 테스트의 첫 질문은 "버리기가 있는 판을 더 하고 싶어 하는가"다.

## 준비

1. **기록 넓히기.** S15의 기록에 배마다 다음을 더한다: 끌어안기를 시작한 횟수, 3초를 채운 횟수(성공), 되찾기 횟수, 다시 들기 횟수, 참가자마다 버려진 점수.
2. **사람과 기기.** S16과 같다. 4명, 폰 한 대 이상, 음성 통화. 되도록 S16에 왔던 사람들로 한다. 버리기가 없던 판을 기억하는 사람이 견줄 수 있다.
3. **설명하지 않는다.** 버리기가 생겼다는 것도 말하지 않는다. 누가 먼저 찾아내는지, 얼마나 걸리는지를 본다.

## 결과에 따른 결정

S16과 같이 한 번에 하나만 바꾸고 16척을 다시 잰다.

| 본 것 | 뜻 | 바꿀 것 |
| --- | --- | --- |
| 넷 중 셋 이상이 버리기 없는 판을 더 하고 싶어 한다 | 버리기가 재미를 깎는다 | `HUG_ENABLED`를 끄고 3묶음으로 간다. S18에서 S20까지의 코드는 남겨 둔다. 한 문장 규칙은 그대로다 |
| 둘씩 갈린다 | 버리기의 값이 안 맞아서일 수 있다 | 아래 줄 가운데 걸린 것을 하나 고치고, 켠 판 16척과 끈 판 8척을 다시 해서 묻는다. 그래도 갈리면 켠 채로 3묶음으로 가고 S26에서 한 번 더 묻는다 |
| 끌어안기 성공이 시작의 절반을 넘는다 | 버리기가 너무 잘 통한다 | `HUG_TIME`을 3에서 4로 |
| 끌어안기 성공이 열에 둘에 못 미친다 | 버리기가 거의 안 통한다 | `HUG_TIME`을 2.5로 |
| 끌어안기 시작이 싣기의 절반을 넘는다 | 버리기가 너무 싸다 | 물에서 나오는 시간을 4.5에서 6으로. `WATER_SPEED`와 `LADDER_CLIMB_TIME`으로 맞춘다 |
| 24척 동안 끌어안기 시작이 다섯 번에 못 미친다 | 버리기가 너무 비싸거나 안 보인다 | 물에서 나오는 시간을 3으로 |
| 실수로 끌어안은 사람이 있다 | 꾹 누르기가 짧다 | `HOLD_TIME`을 0.7로 |
| 끌어안기가 답답하다는 말이 여럿에게서 나온다 | 꾹 누르기가 길다 | `HOLD_TIME`을 0.3으로 |
| 지키는 사람이 한 번도 뚫리지 않고, 다들 종 뒤에 서서 지키기만 한다 | 판이 지키기로 굳었다 | 규칙을 바꾼다: 되찾으면 둘 다 물에 빠진다. `01-rules.md`의 RC-1부터 고치고 S19를 다시 한다 |
| 주인이 옆에서 지키는데도 끌어안기가 자주 성공한다 | 되찾기가 손에 안 닿는다 | `RECLAIM_RANGE`를 8에서 10으로 넓힌다 |
| 한 사람이 버려진 점수의 절반을 넘게 당한다 | 한 사람만 털린다 | 먼저 그 사람이 자리를 비워서인지 본다. 지키는데도 당하면 위와 같이 `RECLAIM_RANGE`를 넓힌다 |
| 띠 안의 도박을 한 사람이 16척 중 12척을 넘게 1등이다 | 도박이 너무 좋다 | `LIMIT_RANGE`의 4명 위 끝을 64로 내린다 |
| 버리기 위주로 한 사람이 16척 중 12척을 넘게 1등이다 | 버리기가 너무 좋다 | `HUG_TIME`을 4로 |
| 8척 안에 아무도 버리기를 찾지 못했다 | 꾹 누르기가 안 보인다 | 남의 상자 앞에서 버튼이 고리로 바뀌는 그림을 키운다. 글로 알려 주지 않는다 |
| 폰으로 한 사람이 경고를 알아채지 못했다 | 경고가 폰에서 안 보인다 | S18의 경고음과 화살표를 키운다. 글로 알리지 않는다 |
| 누르려던 것이 아닌 상자가 자주 잡힌다 | 붐비는 화물칸에서 대상이 뜻대로 안 잡힌다 | `TARGET_RANGE`를 줄이거나, 캐릭터가 바라보는 쪽의 상자를 먼저 대상으로 삼는다. 뒤쪽을 고르면 IN-1의 "가장 가까운 상자"가 바뀌므로 `01-rules.md`부터 고친다 |

## 넘어가는 조건

- [ ] `HUG_ENABLED`를 켠 판 24척, 끈 판 8척의 기록이 있다.
- [ ] 넷 중 셋 이상이 버리기 있는 판을 골랐다. 아니라면 결정 표의 첫 두 줄대로 끄거나 다시 재서 정했다.
- [ ] 실수로 끌어안은 사람이 없다.
- [ ] 한 방식이 16척 중 12척을 넘게 이기지 않는다.
- [ ] 첫 종 뒤 가만히 서 있던 시간의 평균이 7초 이하다.
- [ ] 바꾼 수치와 규칙을 `02-config.md`, `01-rules.md`, 기획 문서에 적었다.
- [ ] 수치를 바꾼 뒤 S17부터 S20까지의 완료 확인을 다시 돌려 모두 통과했다.

## 주의할 곳

- 버리기를 끄는 결정은 실패가 아니다. 기획 문서도 "버리기 없는 판과 비교해 남길지 정한다"고 적어 두었다. 다만 끄면 다른 "넘치면 지는" 게임과의 차이가 줄어든다는 것을 알고 정한다.
- 버리기의 값 셋(꾹 누르기 0.5초, 끌어안기 3초, 물 4.5초)은 합쳐서 8초로, 큰 상자 한 번 싣기(7.5초)와 비슷하게 맞춰져 있다. 하나를 바꾸면 이 합이 바뀐다. 바꾼 뒤의 합을 적어 둔다.
- 끌어안기 시간을 바꾸면 S20에 적은 "둘째 종 뒤에 시작한 끌어안기가 성공할 확률"도 바뀐다. 4초로 늘리면 둘째 종과 동시에 시작해도 63%다.
- 친구끼리는 서로 버리며 웃는다. 모르는 사람끼리는 다를 수 있다. 이 차이는 공개한 뒤에야 보인다(S31의 "공개 뒤 볼 숫자").
