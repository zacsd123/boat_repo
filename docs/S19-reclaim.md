# S19. 되찾기

- **묶음**: 2묶음 · 끌어안기와 되찾기
- **앞 단계**: S18
- **크기(어림)**: 보통
- **끝나면**: 내 상자가 끌어안겼을 때 옆에서 버튼을 톡 누르면 상자는 남고 끌어안던 사람만 물에 빠진다.

## 지킬 규칙

<!--RULES: KR-4 RC-1 RC-2 RC-3 RC-4 IN-4 IN-7 CR-7 BT-9 GP-19-->

| 번호 | 규칙 |
| --- | --- |
| KR-4 | 플레이어 규칙 3: 남의 상자는 꾹 눌러 끌어안고 바다로 뛰어들어 버릴 수 있다. 주인이 옆에서 버튼을 누르면 상자는 남고 나만 빠진다. |
| RC-1 | 주인이 3초 안에 빈손으로 손 닿는 거리(캐릭터 둘 너비)에서 버튼을 누르면 되찾기다. 상자는 제자리에 남고 끌어안던 사람만 물에 빠진다. |
| RC-2 | 되찾기 한 번은 손 닿는 거리에서 내 상자를 끌어안고 있던 모두에게 적용된다. |
| RC-3 | 되찾기를 다시 쓰려면 1초가 지나야 한다. |
| RC-4 | 주인이 상자를 들고 있거나, 물에 있거나, 자기도 끌어안는 중이거나, 멀리 있으면 되찾지 못한다. |
| IN-4 | 빈손으로 갑판에 있으면 톡 누르기는 되찾기다. 끌어안긴 내 상자가 손 닿는 거리에 없으면 아무 일도 일어나지 않고, 앞에 있는 상자에 고리가 잠깐 비쳐 꾹 눌러야 한다는 것을 알려 준다. |
| IN-7 | 버튼의 그림은 지금 누르면 일어날 일에 맞춰 바뀐다. 꾹 눌러야 하는 대상 앞에서는 고리 모양이 된다. |
| CR-7 | 상자를 든 채 얼마든지 버틸 수 있다. 든 상자는 무게도 점수도 아니다. 든 동안에는 끌어안기도 되찾기도 못 한다. |
| BT-9 | 갑판은 끝에서 끝까지 걸어서 1.5초다. 갑판에 빈손으로 있는 주인은 3초 안에 자기 상자 어디든 닿는다. |
| GP-19 | 끌어안긴 내 상자가 손 닿는 거리에 있는 동안에는 버튼을 누르는 순간 되찾기가 된다. 꾹 누르기로 넘어가지 않는다. 급하게 길게 누르다가 다른 상자를 들거나 끌어안는 실수를 막으려는 것이다. |

<!--/RULES-->

당하는 사람의 하나뿐인 대응이다. 이 규칙이 서야 "지키면 못 싣고, 실으러 가면 털린다"는 선택이 생긴다.

## 쓰는 수치

| 키 | 값 | 뜻 |

| `RECLAIM_COOLDOWN` | 1 | 되찾기 재사용 대기(초) |

| `DECK_LENGTH` | 24 | 갑판의 긴 쪽 길이(스터드). 빈손 1.5초 거리다 |

## 만들 것

1. **처리 순서 4번을 채운다.** 단계가 `Loading`이고 상태가 `Empty`이고 갑판 구역 안인 참가자의 `Tap`은 되찾기 시도다.
2. **대상 찾기.** 그 참가자가 주인인 실린 상자 가운데 `HuggedBySlot`이 있고, 주인 캐릭터와 상자 사이의 거리가 `RECLAIM_RANGE` 이하인 것을 모두 모은다. 거리는 서버가 잰다. 상자마다 되찾을 수 있는지는 `InputRules`의 "되찾을 수 있나"가 답한다(S03).
3. **있으면.** 모은 상자마다 끌어안기를 끝낸다: `HuggedBySlot`과 `HugEndsAt`을 지우고, 끌어안던 사람을 `WaterService.throwIn`으로 던진다. 상자는 제자리에 그대로 있다. 무게와 점수는 바뀌지 않는다. 주인의 "다음 되찾기 가능 시각"을 지금 + `RECLAIM_COOLDOWN`으로 적는다.
4. **없으면.** S17의 힌트 `Fx`만 보낸다.
5. **대기 중이면.** "다음 되찾기 가능 시각" 전에 온 `Tap`은 되찾기로 처리하지 않는다.
6. **되찾을 것이 있으면 누르는 순간 되찾기.** 클라이언트는 내 상자 가운데 끌어안긴 것이 `RECLAIM_RANGE` 안에 있으면 버튼 그림을 되찾기 그림으로 바꾸고, 누르는 순간 바로 `Tap`을 보낸다. 이때는 고리를 띄우지 않고 꾹 누르기로 넘어가지 않는다(GP-19).
7. **연출.** 주인이 상자를 잡아채고, 끌어안던 사람이 뒤로 날아가 물에 빠진다. 설명 없이 "주인이 누르면 저렇게 된다"가 보여야 한다.

## 하지 않는 것

- 남의 상자를 대신 되찾아 주는 기능을 만들지 않는다. 되찾는 것은 주인뿐이다.
- 되찾기 버튼을 따로 만들지 않는다. 같은 버튼의 톡 누르기다.
- 되찾기에 성공한 사람에게 점수나 보상을 주지 않는다.

## 완료 확인

끌어안기가 시작된 지 1초 됐을 때 주인이 버튼을 톡 누른다.

- [ ] 주인이 상자에서 5스터드 거리, 빈손: 상자는 남고 끌어안던 사람이 물에 빠진다.
- [ ] 주인이 상자에서 9스터드 거리: 아무 일도 없다. 앞 상자에 고리 힌트만 비친다.
- [ ] 주인이 상자를 들고 있다: 되찾기가 아니라 놓기가 된다.
- [ ] 주인이 물속이다: 아무 일도 없다.
- [ ] 주인이 다른 사람의 상자를 끌어안는 중이다: 아무 일도 없다.
- [ ] 주인이 선착장에 있다(갑판 밖): 되찾기가 아니다.

그 밖의 경우.

- [ ] 내 상자 둘을 두 사람이 따로 끌어안고 있고 둘 다 8스터드 안: 톡 한 번에 두 사람 모두 물에 빠진다.
- [ ] 하나는 8스터드 안, 하나는 밖: 안쪽만 되찾는다. 바로 걸어가서 1초 안에 다시 눌러도 되찾지 못한다. 1초가 지난 뒤에 누르면 된다.
- [ ] 3초가 찬 뒤에 누르면 늦었다. 상자는 이미 없다.
- [ ] 남의 상자가 끌어안기는 옆에서 내가 눌러도 아무 일도 없다.
- [ ] 되찾기를 당한 사람이 물에서 나와 갑판에 다시 서기까지 4.5초(±0.3)다.
- [ ] 갑판 통로의 가장 먼 곳에 빈손으로 서 있다가 경고를 보고 걸어가면 3초 안에 되찾을 수 있다.
- [ ] 해변의 더미 앞에서 경고를 보고 걸어가면 3초 안에 되찾지 못한다. 가장 닿기 쉬운 입구 바로 앞 칸의 상자로 시험한다.
- [ ] 폰에서 경고 화살표를 보고 걸어가 톡 누르는 흐름이 막힘 없이 된다.
- [ ] 끌어안긴 내 상자가 8스터드 안에 있을 때 버튼을 1초 동안 길게 눌러도 되찾기만 되고, 옆의 다른 상자가 들리거나 끌어안기지 않는다.
- [ ] 서버를 켤 때 도는 규칙 시험(S03)이 전부 통과한다.

## 주의할 곳

- 끌어안기가 3초에 끝나는 것과 되찾기가 같은 프레임에 오면, 서버가 먼저 처리한 쪽이 이긴다. 되찾기의 `Tap`이 먼저 처리되면 되찾기다.
- 되찾기의 거리는 주인과 상자 사이다. 주인과 끌어안는 사람 사이가 아니다.
- 더미 앞의 주인이 못 미치는 것은 간발의 차다. 더미에서 갑판 입구까지 빈손으로 3.0초이고 끌어안기도 3초라서, 경고를 보고 움직이기까지의 짧은 시간만큼 늦는다. 기획 문서가 끌어안기를 3초로 잡은 까닭이 이것이다("돌아오던 주인은 되찾고 더미 앞의 주인은 못 미친다"). 맵을 고치다 이 거리가 3.0초보다 짧아지면 해변에서도 되찾게 되어 "실으러 가면 털린다"가 사라진다. 맵을 손댈 때마다 S04의 초시계 확인을 다시 돌린다.
- 한곳에 상자를 모아 두고 그 옆에 서 있는 사람은 몇 명이 덤벼도 한 번에 되찾는다. 이것이 한 사람만 계속 털리는 것을 막는 장치다. 대신 그 사람은 서 있는 동안 싣지 못한다. 이 맞바꿈이 실제로 어떻게 쓰이는지는 S21에서 본다.
- 지키는 사람이 한 번도 뚫리지 않아 판이 굳으면 기획 문서가 적어 둔 다음 수는 "되찾으면 둘 다 물에 빠진다"다. 그건 규칙을 바꾸는 일이므로 S21의 결과를 보고 `01-rules.md`부터 고친다.
